# DSP numérique

Application de découverte sociale et patrimoniale (DSP) pour iPad, utilisable hors connexion.

- Ce dépôt contient uniquement le code de l'application.
- Aucune donnée client n'est stockée ici : les dossiers restent sur l'appareil.
- Les textes de la méthode d'entretien ne sont pas publiés ici : ils sont importés une seule fois sur l'iPad.
